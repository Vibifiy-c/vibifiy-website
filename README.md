## 🚀 Getting Started

### Prerequisites

- A modern web browser (Chrome, Firefox, Safari, Edge)
- A local text editor or IDE
- Git

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/Vibifiy-c/vibifiy-website.git
   cd vibifiy-website
   ```

2. **Open the website**
   - Option A: Open `index.html` directly in your browser
   - Option B: Use a local development server (e.g., Live Server in VS Code)

### Local Development Server

If using VS Code, install the Live Server extension and right-click on `index.html` to "Open with Live Server" for automatic refresh on file changes.

Alternatively, use Python's built-in server:
```bash
# Python 3
python -m http.server 8000

# Python 2
python -m SimpleHTTPServer 8000
```

Then navigate to `http://localhost:8000` in your browser.
